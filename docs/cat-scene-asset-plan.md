# 猫咪陪伴 - 场景与素材蓝图

## 制作原则

- 所有正式场景底图都必须是**空房间**：没有人、没有猫、没有猫影。
- 猫咪、猫影、以及少数会遮住猫的家具前景分别输出，网页在运行时叠放它们。
- 当前 `room-master-ipad-v3.png` 仅作为房间总览的构图参考；正式上线前需按同一布局生成无猫版本。
- 全部场景统一为 `4:3` 横屏，以 iPad 横屏为基准。

## 初始房间与解锁家具

### 初始即有

- 书桌、电脑、椅子、台灯与笔筒
- 床、床头柜、床头灯、床头书架与装饰
- 圆地毯
- 门、窗、窗帘、墙面与地板等房间结构

### 小鱼干购买后加入

- 沙发：解锁占座、埋抱枕、睡歪等待机动作。
- 猫爬架：解锁抓柱子、趴高台、看窗外等待机动作。

因此，正式的初始空场景不能把沙发或猫爬架画进底图。它们各自是独立家具层，并在购买后才显示、才加入对应的猫咪动作池；其他初始布置不得因购买逻辑而被删除或替换。

## 猫咪动作包

每个动作输出透明 PNG 或 WebP 序列帧，统一保留画面边缘，不裁掉尾巴、耳朵或伸出的爪子。

### 全场景通用

1. 静止呼吸：6 帧循环。
2. 眨眼：4 帧，可叠加在静止状态。
3. 睡姿微动：6 帧循环。
4. 舔爪：8 帧循环。
5. 伸懒腰：8-10 帧，单次播放。

### 场景专属

- 地毯：翻身露肚皮、尾巴轻拍。
- 书桌：跳上桌、用爪子拨鼠标、坐着望窗。
- 床：踩奶、钻进被子、从被子里探头。
- 沙发：埋进抱枕、四脚朝天、打哈欠。
- 猫爬架：抓柱子、探头、在平台趴下。

## 动作与地点组合规则

待机页不是“每件家具只有一种动作”，而是从已解锁地点中抽取一个，再从该地点可用的日常动作中播放。这样同一个动作能在不同位置反复出现，却不会显得机械。

| 动作 | 地毯 | 床 | 沙发 | 猫爬架 | 书桌 |
| --- | --- | --- | --- | --- | --- |
| 打哈欠 | 是 | 是 | 是 | 是 | 是 |
| 翻肚皮 / 四脚朝天 | 是 | 是 | 是 | 否 | 否 |
| 踩奶 | 是 | 是 | 是 | 否 | 否 |
| 挠耳朵 | 是 | 是 | 是 | 是 | 是 |
| 舔爪 / 舔毛 | 是 | 是 | 是 | 是 | 是 |
| 睡觉呼吸 | 是 | 是 | 是 | 是 | 否 |
| 抓柱子 / 看窗外 | 否 | 否 | 否 | 是 | 否 |
| 拨鼠标 / 趴键盘边 | 否 | 否 | 否 | 否 | 是 |

购买沙发或猫爬架后，不是只多一个固定片段，而是把该地点和上表中所有匹配动作加入待机随机池。

## 每个场景的文件组成

```text
scene-name/
  background.png      # 无猫的完整场景
  foreground.png      # 可选：桌沿、被子或平台等遮挡层
  shadow.png          # 猫在固定落点的柔和阴影
  cat-idle-01.png     # 透明背景序列帧
  cat-idle-02.png
  ...
```

## 生成顺序

1. 先生成 `房间总览` 的无猫底图，确认所有家具位置完全锁定。
2. 再生成 5 张空场景近景，并逐张确认猫咪落点。
3. 生成同一只虎斑白猫的地毯动作包，作为动作与比例标准。
4. 完成地毯场景在网页里的分层播放，再复制这一套结构到书桌、床、沙发和猫爬架。

## 第一版边界

- 先只做一只虎斑白猫与 6 个视角。
- 每个视角只需 2-4 个动作，不在第一版制作大量罕见事件。
- 新猫以后复用相同落点、遮挡层和动作类别，只替换透明猫咪动作包。
- 夜景作为后续扩展包保存，当前第一版只制作白天素材。
